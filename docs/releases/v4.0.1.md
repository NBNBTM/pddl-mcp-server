# PDDL MCP Server v4.0.1

This maintenance release strengthens repository reproducibility, security, and contributor onboarding while preserving all four MCP tool interfaces.

## Highlights

- Pins GitHub-owned Actions to full commit SHAs and tests Python 3.10 through 3.14.
- Adds repository policy tests to prevent version and workflow configuration drift.
- Adds a reproducible Docker image with a pinned Fast Downward build.
- Adds an MCP Python client quickstart without undeclared direct dependencies.
- Adds `CODEOWNERS`, contribution guidance, and a Contributor Covenant code of conduct.
- Removes the unused standalone `fastmcp` dependency and an unreferenced error module.
- Aligns project, MCP configuration, server, documentation, and release metadata at version `4.0.1`.

## Compatibility

The public tools remain unchanged:

- `plan_from_text(text, options=None)`
- `generate_plan(task)`
- `validate_config()`
- `get_system_info()`

LLM configuration remains optional. When an LLM is unavailable, the deterministic fallback remains active. Fast Downward can still be configured through `FAST_DOWNWARD_PATH`; the Docker image includes a pinned planner build.

## Security

No credentials are included in the repository or container image. Runtime secrets must be supplied through environment variables and must never be committed.
